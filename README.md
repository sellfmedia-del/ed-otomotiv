# ED Otomotiv

ED Otomotiv'in Vercel üzerinde yayınlanan statik web sitesi.

## Yayın yapısı

- Üretim çıktısı: `dist/`
- Ana alan adı: `https://www.edotomotiv.net/`
- Vercel ayarları: `vercel.json`

`main` dalı üretim kaynağıdır. İçerik veya teknik SEO değişiklikleri yayınlanmadan önce bağlantı, metadata, sitemap ve robots kontrollerinden geçirilmelidir.
